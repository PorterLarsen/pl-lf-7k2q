Add other lead lists

Import any spreadsheet saved as CSV — for example Notices of Default, trustee sales, probate cases, code violations, or an export from PropStream. It needs a column with the parcel ID (like 05-032-0007) or the street address. Matching properties get a tag and a score boost; properties not behind on taxes are added as extra leads. Lot and building details are added for them on the next Refresh when a parcel ID is given.

Where the data comes from

Unpaid back taxes: Cache County Treasurer's public delinquent-tax map service. Lot size, building size, year built and market value: Utah's statewide tax-parcel layer (UGRC), updated yearly by the county assessor. Tax-sale eligible means taxes have gone unpaid long enough that the county can list the parcel at its May tax sale unless it's paid first. Market value is the assessor's figure, not an appraisal. Scores are for sorting only: check title, liens and condition before making an offer.
